# 缺口计划

一个纯前端、可安装到 iPhone 主屏幕的热量缺口记录 PWA。

## 固定规则

- 目标减重：5 斤
- 总目标缺口：15,000 大卡
- 每日标准摄入：1,600 大卡
- 当日缺口：1,600 − 当日实际摄入
- 计划换算：3,000 大卡缺口 = 1 斤

只有添加过食物的自然日才计入累计缺口；超过 1,600 大卡会产生负缺口。

## 功能

- 200+ 常见食物参考值，支持分类和搜索
- 支持“本次总千焦”和“每 100 克千焦”两种包装录入方式
- 按日期保存饮食记录，自动计算当日、累计和剩余缺口
- 数据仅保存在当前浏览器，可导出和导入 JSON 备份
- 支持离线打开和 iPhone Safari 添加到主屏幕

## 隐私

本项目不含登录、统计脚本或后端服务，不上传饮食记录。公开网站仅公开程序代码，用户录入的数据保存在各自设备的浏览器本地存储中。

## 说明

食物热量为常见参考值，实际值会因品牌、配方和烹饪方式变化。包装食品应优先使用包装营养成分表。“3000 大卡 = 1斤”为本 App 的自定义计划公式，不替代医学或营养建议。
